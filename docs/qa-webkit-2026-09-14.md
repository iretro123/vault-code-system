## Limits / not a release certification

These are WebKit browser viewports, not signed Capacitor builds. Native safe-area values, keyboard, gesture handling, push, app switching, and actual hardware text scaling are not covered. The tests use empty synthetic backend collections, so course playback, PDFs, long real conversations, attachments, moderation, saved profile edits and other authenticated write paths are not exercised. Below-fold reachability is programmatic and is not proof every touch gesture is correct. The native horizontal-scroll issues in qa-native-release-2026-09-14.md remain separate from this browser-layout pass (main agent may be addressing them).

The independent first and second passes overlapped ongoing local fixes by other agents; results describe the running local app during the run, not a frozen signed release artifact.
